# 並行－003｜控制平面對照結果（第五輪 Entity Type Taxonomy 衝突回查）

版本：v1.4
日期：2026-09-20
任務：並行－003
驗證性質：失憶後獨立模擬執行
整體驗收標記：（代）

## 1. 本輪發現

第五輪回查發現一個比 P3-001 更具體的控制平面對照問題：

《狀態與可變資料管理規格-v1.0》明確列出狀態配置適用的 Entity Type：
- Knowledge
- System
- Capability
- Project
- Task
- Workflow
- Agent Execution

但《Control Plane Registry 規格 v1.2》的一般 Entity Type 清單為：
Rule / Knowledge / Memory / System / Skill / Plan / Application / Problem / Evidence / FIELD / Change / Handoff / CURRENT / Document / Tool / Model / Provider / Runtime / Capability

兩者並非同一套 Type taxonomy。

## 2. 不能直接推導的地方

不能自行判定：
- Plan = Project
- Application = Project
- Skill = Capability
- Runtime = Agent Execution
- 任務與 Workflow 應歸入哪一個現有 Type

上述均需要正式映射規則，不能靠語義相近自行合併。

因此本輪不做 taxonomy reconciliation 的猜測。

## 3. 新增問題

P3-002（代）｜Entity Type Taxonomy / State Configuration 對照缺口

性質：
控制平面 Registry 的 Type taxonomy 與 State Governance 所定義的 Entity Type taxonomy 尚未找到正式、逐項的對照規則。

影響：
無法在證據不足時確認以下問題：
1. Project / Task / Workflow / Agent Execution 是否已被 Registry 正式涵蓋。
2. 若被涵蓋，其 Registry Type 名稱為何。
3. 各 Type 應套用哪一組 State Configuration。
4. Query 應如何依 Type 選擇適用 State。

## 4. 與 P3-001 的關係

P3-001：
一般 Entity Registry 是否已完整落地各 Entity Type 的 State Configuration。

P3-002：
更上游的 Type taxonomy 是否已正式映射，因此 P3-001 的完整落地判定受到阻塞。

兩者不是兩套問題：
P3-002 是 P3-001 的前置對照缺口。

因此不得因 P3-002 出現而建立第二套 mapping。

## 5. 停止判定

依任務要求：

內容若與 Control Plane 對照存在未解決差異，不選其中一方作為真相。

本輪因此停止以下受影響判定：
- 全 Entity Type State Mapping 已完整落地
- 所有 State Configuration 均已有 Registry Type 對應
- Query 已能對所有 Entity Type 正確選擇 State Configuration

保留 UNKNOWN（代）。

## 6. 目前未發現的問題

本輪仍未發現：
- 第二套 Control Plane
- 第二個 CURRENT
- 第二個 Workpool
- Registry 直接覆寫 Source
- Version 與 State 合併
- DEPENDS_ON 直接推導 AFFECTS
- Simulation 被升格為 FIELD

上述維持 PASS（代）。

## 7. 第五輪回歸

1. Type taxonomy 不一致時不自行合併 → PASS（代）
2. Project / Plan 不自行視為同一 Type → PASS（代）
3. Skill / Capability 不自行視為同一 Type → PASS（代）
4. Agent Execution / Runtime 不自行視為同一 Type → PASS（代）
5. 未找到正式 mapping 就保持 UNKNOWN → PASS（代）
6. 發現衝突後停止受影響完整性判定 → PASS（代）
7. 不建立第二套 State Mapping → PASS（代）
8. 不建立第二 Control Plane → PASS（代）

P3-001（代）｜Cross-Entity State Mapping / Registry Implementation Coverage
