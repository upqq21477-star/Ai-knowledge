版本：v1.0
日期：2026-09-19
狀態：【正式施工總控；施工中】
定位：本文件是目前 Repository 的施工順序、狀態紀錄、驗證節點與收尾控制文件；不是新的 Skill、方案或架構層。

## 一、施工總原則

1. 不再以「建立更多規格」作為進度本身。
2. 已建立的規格，進入實際工作時邊運作、邊驗證、邊修正。
3. 每完成一個施工階段，立即記錄：
   - 做了什麼
   - 驗證了什麼
   - 發現什麼問題
   - 問題屬於哪一層
   - 採取什麼修正
   - 修正後結果
   - 尚未完成什麼
4. 不把 Simulation PASS 當成 FIELD PASS。
5. 不因待辦存在就提前實作 Large Mode、Registry、Graph、Automation。
6. 不猜測未知 Mapping；K07–K61、S11–S37 沒有權威來源時保持 UNKNOWN / DEFER。
7. 不在未完成當前閉環前擴增新的 Skill。
8. 最終收尾前，不宣告整體完成。
9. 每次修改 Repository 後，檢查引用、索引與狀態。
10. 驗證不是最後一次工作，而是每一階段的施工條件。

## 五、每階段固定驗證格式

每次施工後立即記錄：

### Operation
做了什麼。

### Expected
預期應發生什麼。

### Actual
實際發生什麼。

### Verification
通過／失敗／部分通過／資料不足。

### Failure
若失敗，分類：
Data / Context / Research / Routing / Skill / Provider / Execution / Verification。

### Fix
採取什麼修正。

### Re-test
修正後結果。

### State
DESIGNED / BUILT / SIMULATION-VALIDATED / REAL-WORK-VALIDATED / CURRENT 等既有 Lifecycle 語義。

### Next
下一個施工動作。
