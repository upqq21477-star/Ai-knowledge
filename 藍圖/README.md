`藍圖/規劃/`

- AI 單人工作室功能導向藍圖與 Mapping
- AI 單人工作室整體工程最新藍圖

- Skill 小規模／大規模擴展規劃
- 工程施工總控與收尾計畫
- 藍圖交接資料

原則：
1. 藍圖／規劃中的內容不等於正式工程已實體化。
2. 正式 CURRENT 工程狀態仍由 CURRENT Baseline 與正式系統文件決定。
3. 規劃完成、文件完成、模擬驗證與實際採用必須分開。
4. 新的規劃類文件優先放入「規劃」。
5. Git 歷史保留原始搬移與變更鏈；不以舊路徑判斷目前狀態。
