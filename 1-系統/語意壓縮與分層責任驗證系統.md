# 語意壓縮與分層責任驗證系統

版本：v1.0
核心能力：Semantic Compression & Layer Validation
狀態：【候選 System；由 Knowledge 建立】

## 功能

將待壓縮的 Knowledge／System／Solution 文件，依「最小充分語意」原理拆解，判定每段語意應保留、移交、合併或刪除，並驗證壓縮後是否仍可正確執行。

## 輸入

- 原始文件
- 壓縮候選文件
- 所屬層級
- 任務／方案目的
- 已知驗收條件

## Knowledge

使用：
0-知識/語意壓縮與分層責任原理-v1.0.md

## 執行

1. 識別每段語意的功能。
2. 判定其責任層。
3. 標記：不可刪／可移交／可合併／冗餘。
4. 產生壓縮版本。
5. 對照原版檢查身份、路由、功能、依賴、結果解讀、驗收。
6. 發現缺失時定位到具體語意。
7. 只補最小必要語意。
8. 重測。

## 輸出

- Semantic Map
- Compression Result
- Missing Semantic
- Layer Assignment
- Validation Result
- Token／Context Difference
- Error Classification

## 固定判定

若刪除造成：
- 身份改變 → 失敗
- 路由改變 → 失敗
- 功能改變 → 失敗
- 依賴錯誤 → 失敗
- 結果解讀改變 → 失敗
- 驗收改變 → 失敗

若只刪除不影響上述項目的重複／背景語意，可接受。

## 邊界

本 System 不決定特定方案的最終目的與驗收標準。
本 System 不替代 Knowledge。
本 System 不自行決定正式組／對照組路由。

## 驗證

至少使用：
- 原版／壓縮版 A/B
- 相同 Knowledge
- 相同任務
- 多次重複測試

並記錄：
Token 成本、路由、功能、語意失真、Grounding、驗收正確率。

注意：單次模擬不得視為真實模型可靠率。
