# 上下文可靠性測試系統

版本：v1.1
所屬方案：上下文成本與可靠性控制方案（候選）
核心能力：C04｜Context Reliability Test
狀態：【候選系統；待最小實測】

## 一、System 職責
比較 Context 大小與組成改變後，AI 的理解、Recall、規則一致性與輸出是否出現非預期漂移。

## 二、Knowledge 調用
執行前調用：
- 0-知識/上下文/上下文管理原理.md
- 0-知識/上下文/Context Reliability Test-上下文可靠性測試原理.md
- 0-知識/更新/目前狀態判定.md
- 0-知識/更新/區分目前狀態與設計歷史.md

證據／變化判定調用：
- 0-知識/證據/來源主張證據追溯.md
- 0-知識/比較/知識比較原理.md
- 0-知識/比較/知識衝突判定.md

## 三、既有 System 調用
- 上下文預算與充分性測量系統：提供 Context 梯度。
- 來源、證據與研究採用判斷系統：確認證據與條件。
- 知識比較、更新與資料演化系統：處理測試後的狀態／知識變化。

## 四、輸入／輸出
輸入：Task + Context Profile/Context Gradient + Rules + Evidence。
輸出：Reliability Profile，至少包含理解結果、關鍵資訊 Recall、規則一致性、輸出穩定性、合理變化／非預期漂移分類、Context 敏感條件。

## 五、最小驗證
至少測短／基準／長／過量 Context，並控制單一主要變因。
無法形成可重現分類時，不升格。
