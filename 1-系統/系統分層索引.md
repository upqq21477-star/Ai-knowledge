## 判斷規則

- Skill：內容定義可觸發、可執行能力。
- System：長期可被調用的系統能力與治理。
- Spec：規格／契約／介面／定義。
- Evidence：FIELD／Simulation／Acceptance／Audit／Pressure Test。
- Research：外部比對與研究材料。

## Runtime 原則

Task → Skill Selection → 必要 System / Spec → 必要 Knowledge / Plan → Execution → Verification。
Evidence / Research 僅在需要查證、研究或回溯時載入。
