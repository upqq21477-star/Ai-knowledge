# 上下文證據一致性與幻覺檢測系統

版本：v1.1
所屬方案：上下文成本與可靠性控制方案（候選）
核心能力：C05｜Hallucination Detection
狀態：【候選系統；待最小實測】

## 一、System 職責
將 AI 輸出拆成可驗證主張，調用證據判定，並比較 Context 條件以識別 Context-induced Error。

## 二、Knowledge 調用
執行前調用：
- 0-知識/證據/來源主張證據追溯.md
- 0-知識/證據/資訊可信度與主張驗證原理.md
- 0-知識/上下文/Context Grounding and Hallucination Detection-上下文失真與幻覺檢測原理.md

需要判斷目前／歷史資料時調用：
- 0-知識/更新/目前狀態判定.md
- 0-知識/更新/區分目前狀態與設計歷史.md

## 三、既有 System 調用
- 上下文預算與充分性測量系統：取得 Context 梯度／Context Profile。
- 上下文可靠性測試系統：取得 Reliability Profile。
- 來源、證據與研究採用判斷系統：確認來源與證據採用狀態。

## 四、輸入／輸出
輸入：AI Output + Context + Evidence + Context Profile/Reliability Profile。
輸出：Grounding / Hallucination Detection Result，至少包含 Atomic Claims、Evidence Mapping、Supported、Contradicted、Unsupported、Uncertain、Context-induced Error 判定、可重現條件。

## 五、最小驗證
建立已知 Supported／Unsupported／Contradicted 的主張，再以不同 Context 梯度重測。
無法穩定區分時，不升格。
