# 上下文預算與充分性測量系統

版本：v1.1
所屬方案：上下文成本與可靠性控制方案（候選）
核心能力：C03｜Context Budget
狀態：【候選系統；待最小實測】

## 一、System 職責
依任務測定最小可靠 Context 與 Context 的成本／效益變化。
本 System 不重述上下文管理原理。

## 二、Knowledge 調用
執行前調用：
- 0-知識/上下文/上下文成本.md
- 0-知識/上下文/上下文管理原理.md
- 0-知識/上下文/Context Budget-任務上下文預算與最小充分上下文.md

證據判定調用：
- 0-知識/證據/來源主張證據追溯.md
- 0-知識/證據/資訊可信度與主張驗證原理.md

Knowledge 提供原理與判定規則；本 System 負責執行測量。

## 三、既有 System 調用
- 研究問題、資料探索與搜尋系統：取得候選 Context。
- AI知識與上下文交接系統：取得任務與執行 Context。
- 來源、證據與研究採用判斷系統：確認證據支持程度。

## 四、輸入／輸出
輸入：Task + Candidate Context + Model/Test Conditions。
輸出：Context Profile，至少包含 Context 梯度、尺寸、結果、正確性／規則一致性、證據覆蓋、最小可靠 Context、飽和／可能下降點。

## 五、最小驗證
同一任務建立：短 → 最小充分 → 完整相關 → 過量。
無法重現足夠／不足／可能過量的差異時，不升格。
