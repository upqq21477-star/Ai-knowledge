# 上下文預算與充分性測量系統

版本：v1.0
所屬方案：上下文成本與可靠性控制方案（候選）
核心能力：C03｜Context Budget
狀態：【候選系統；待最小實測】

## 一、定位
把「最小充分 Context」從概念轉為可重複測量流程。

本系統不負責搜尋引擎；搜尋能力由既有研究／搜尋系統提供。

## 二、流程
~~~text
任務
↓
建立基準 Context
↓
建立 Context 梯度
↓
逐級執行相同任務
↓
測量正確性／規則一致性／證據支持
↓
比較成本與性能
↓
找出最小可靠 Context
↓
記錄任務 Context Profile
~~~

## 三、Context Profile
至少保存：
- 任務。
- 模型。
- Context 組成。
- Context 尺寸。
- 關鍵證據覆蓋。
- 結果。
- 評估。
- 最小可靠級別。
- 飽和點。
- 可能性能下降點。
- 限制。

## 四、與既有系統接口
- 研究問題、資料探索與搜尋系統：提供候選資料。
- AI知識與上下文交接系統：提供任務與 Context 執行入口。
- 來源、證據與研究採用判斷系統：判定證據是否足以支持結果。
- 問題解決與新系統建立流程：處理測試失敗與候選修正。
- 知識比較、更新與資料演化系統：當 Context Profile 因模型／資料變更失效時重新驗證。

## 五、最小驗證
至少選一個實際任務，建立四級 Context：
短／最小充分／完整相關／過量。

若無法可靠區分哪一級開始足夠，本系統仍為候選。
