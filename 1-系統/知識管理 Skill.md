# 知識管理 Skill（Knowledge Management Skill） v1.0

版本：v1.0
日期：2026-09-19
狀態：【建立；待實際運作驗收】

## 1. 定位
管理可長期引用資料的生命週期、來源與結構，不負責決定目前任務應載入哪些 Context。

## 2. 核心責任
- 保存可重用 Knowledge。
- 區分 Canonical Source 與 Derived View。
- 管理來源、版本與狀態。
- 避免把一次性決策永久寫成 Knowledge。
- 對未知資料保持 UNKNOWN。

## 3. Input
驗證後資訊、既有 Knowledge、來源與版本資料。

## 4. Output
- Knowledge Item
- Source / Provenance
- Version
- Lifecycle Status
- Derived View（若有）

## 5. 邊界
Context Management 決定「現在載入什麼」；Knowledge Management 決定「資料如何保存與管理」。

## 6. 原則
Mapping 不等於 Canonical Source；不要建立第二套真實資料庫。
