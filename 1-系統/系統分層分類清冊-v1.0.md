# 系統分層分類清冊 v1.0

日期：2026-09-19
狀態：【施工中；分類初版】
目的：把現有「1-系統」根目錄文件先依責任分類，作為後續實體搬遷前的對照基線。

## 1. 本輪原則

本清冊先做「責任分類」，不直接搬檔。
分類優先依文件實際定位，而非單看檔名；檔名無法確定責任時保留人工複核。

正式分層：
- 00-核心入口：入口、索引、最小控制契約。
- 01-Skill：可被 Agent 選取／觸發的工作責任 Definition。
- 02-System：長期可呼叫的穩定系統能力。
- 03-Spec：契約、規格、介面、流程定義。
- 04-Evidence：FIELD、Simulation、Acceptance、Audit、Pressure Test、實際工作證據。
- 05-Research：外部研究、候選、比對與尚未提升為正式能力的研究材料。

本清冊完成前不進行大規模實體搬遷。
