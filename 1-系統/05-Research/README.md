# 05｜Research

本層保存外部比對、研究、候選方案與尚未升格為正式能力的研究材料。

## 邊界

Research 提供研究依據，不直接等同於正式 Knowledge、System 或 Skill。

- 外部比對紀錄 → 本層
- 候選方法／研究材料 → 本層
- 研究運作規則 → 由 02-System 管理
- Research Skill → 由 01-Skill 管理
- 研究結果若升格為正式原理 → 回到 Knowledge / System / Spec 的正式層
