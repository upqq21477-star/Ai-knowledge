## 五、0-知識／系統 與 1-系統 的邊界

本批確認：

**0-知識／系統 = 系統設計、依賴、介面與演化的知識原理。**

**1-系統 = 實際可重複工作的系統結構。**

因此不能因為兩者都出現「系統」一詞，就把兩者視為重複。
