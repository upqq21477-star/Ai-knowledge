## 四、核心結果

### 1. 沒有發現英文舊層的核心文件完全未被中文正式層吸收

本次 9/9 均找到中文正式對應。

因此目前沒有證據支持「英文層存在一批中文正式層完全遺漏的核心知識」。

此結論只對目前 Repository 中的 9 個英文 Markdown 成立。

### 2. 中文正式層不是英文層的單純複製

中文層目前已形成：

- 上下文
- 分類
- 搜尋
- 更新
- 比較
- 管理
- 系統
- 證據
- 運作

等功能分類。

因此 `0-知識/` 已是演化後的正式知識結構，而 `0-knowledge/` 是早期平面結構。

### 3. 「知識分類」是規格演化，不是單純搬移

英文舊版提出五種最小功能分類：

- 定義
- 原理
- 方法
- 判斷
- 驗證

中文正式版後來已形成實體 Repository 功能分類：

- 分類
- 管理
- 搜尋
- 證據
- 比較
- 更新
- 系統
- 上下文

並明確說明舊的 `0-知識/知識/` 是過渡結構。

因此不能把英文版分類原理與中文正式版目前目錄結構視為同一份規格。

### 4. 「知識定義與邊界」存在實質規格演化

英文舊版把知識定義為可跨場景重用的基本原理、判斷或方法。

中文正式版經外部研究後已修正：

- 取消「必須跨場景」。
- 不再把「必須獨立理解」作為絕對條件。
- 分離 Knowledge 與 Document。
- 分離 Knowledge 成立與可信程度／驗證狀態。
- 納入情境性、程序性、經驗形成的知識。
- 不採用「資料→資訊→知識→智慧」作為硬規則。

因此此項屬於「舊內容被 CURRENT 版本演化吸收」，不是單純 Duplicate。

較精確的判定：

- `0-知識/`：目前正式知識 Namespace。

- 本報告：Derived Evidence。

不能因中文目錄較新就自動把所有中文文件升格為 Canonical；仍須遵守 State 與 Source Trace。
