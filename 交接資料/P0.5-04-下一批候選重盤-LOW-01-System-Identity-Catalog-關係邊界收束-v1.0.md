## 二、全文語義結果

### 1. System Identity
System ID 是穩定身份；Name 是人類可讀名稱；Path 是 locator。改名、移動、方案歸屬變更不應自動造成身份失效。Trigger 等跨文件關係應引用 System ID。

責任：Identity Semantic。

### 2. System Catalog / Registry
保存正式系統的最小身份、定位與高階 metadata；不複製完整 System Content；不成為所有動態狀態的唯一真實來源；詳細內容回原 System 文件。

責任：Catalog / Index Semantic。

### 3. Catalog Scaling
全域 Registry + 多視圖；同一 System ID；只有實際搜尋、維護、一致性問題出現才考慮物理分片；分片不得產生第二份正式身份。

責任：Catalog Evolution / Scale Semantic。

### 4. System Definition
回答「什麼才算 System」。它不是 Identity，也不是 Catalog。

### 5. System Dependency
回答「什麼情況構成依賴」。Dependency 是 Relationship 的一種。

### 6. Common Relationship Model
回答 Source → Relationship Type → Target，其中 dependsOn 是關係類型之一。因此 Relationship Model 不取代 System Dependency；System Dependency 也不是第二套 Relationship Registry。
