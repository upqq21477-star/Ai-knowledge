## 討論記錄規則

討論過程不直接等同正式決策。每次重要討論完成後，將重點摘要、主要論點、研究結果、待確認事項、形成的決策與後續行動彙整成會議記錄，保存於本資料夾。

外部研究採用「研究 → 比對 → 評估 → 採用」流程；討論中的候選方案不得自動視為正式架構。

本分類目前作為研究與討論的工作分類，後續若研究證明分類需要調整，應透過正式討論與記錄進行變更。
