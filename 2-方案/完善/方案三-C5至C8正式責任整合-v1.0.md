# 方案三-C5至C8正式責任整合 v1.0

版本：v1.0  
狀態：【責任整合完成；模擬回歸待驗證】  
日期：2026-09-17

## 一、整合目的

將 C5～C8 正式接入方案三責任鏈，不修改第一版功能清單，不新增大型獨立系統。

正式鏈：

```text
C1 → C2 → C3 → C4 → C5 → C6 → C7 → C8 → C9
```

## 二、正式責任

### C5 既有能力盤點

負責確認目前是否已有資料、知識、能力、系統、流程或方案可完成 Change Objective。

核心判定：

```text
SUFFICIENT
PARTIAL
OVERLAPPING
UNVERIFIED
INACTIVE
OBSOLETE
MISSING
```

不得因需求出現而直接新增系統。

### C6 影響分析

負責沿著 Identity、Relationship、Dependency、Version、State、Lifecycle 與使用路徑分析潛在影響。

輸出的是 Potential Impact，不是 Actual Outcome。

至少記錄：

```text
Affected Object
Relationship Path
Impact Type
Direct / Indirect
Evidence
Confidence
Assumption
Potential Risk
Potential Rework
Verification Case Affected
Unknown Area
```

### C7 演化必要性判定

負責判斷是否有充分理由進入演化設計。

輸出：

```text
EVOLUTION-REQUIRED
EVOLUTION-NOT-REQUIRED
DEFER
NEED-MORE-EVIDENCE
OUT-OF-SCOPE
```

不得把「需要演化」解讀成「已選定候選方案」。

### C8 候選變更產生

負責將已確認的演化需求轉成可比較、可驗證的候選。

支援：

```text
Add
Correct
Extend
Partial Replace
Replace
Merge
Split
Migrate
```

每個候選至少保留：

```text
Candidate ID
Type
Target
Description
Scope
Expected Effect
Dependencies
Assumptions
Risks
Migration Need
Compatibility Concern
Effort / Cost
Reversibility
Success Criteria
Required Validation
Known Unknowns
```

不得直接採用、執行、刪除或宣告成功。

## 三、共同語義

C5～C8 使用方案一共同語義：

```text
Identity
Source
Evidence
Claim
State
Version
Relationship
Lifecycle
History
Traceability
Impact
```

不得建立第二套身份、版本、關係或證據模型。

## 四、跨方案接口

```text
方案二 B12/B15/B16
        ↓
C1～C4
        ↓
C5 既有能力盤點
        ↓
C6 影響分析
        ↓
C7 演化必要性
        ↓
C8 候選變更
        ↓
C9
```

問題解決系統可以提供候選解法，但不能繞過 C5～C7 將其直接寫成正式演化。

若 C5～C8 發現問題已成為長期能力重疊、責任重構或系統整理問題，可以形成方案四蒸餾候選，但不得自行執行方案四重構。

## 五、責任停止條件

```text
C5：已有能力足夠 → 不新增能力
C6：影響未知且無法合理分析 → 保留 UNKNOWN，不假設安全
C7：證據不足 → NEED-MORE-EVIDENCE / DEFER
C8：候選未經後續分析 → 不採用、不執行
```


## 七、整合結論

C5～C8 現在成為方案三正式中段責任。

```text
研究：完成
模擬實作驗收：PASS
責任整合：完成
模擬回歸：待驗證
FIELD：未驗證
```

本整合不代表方案三完成。
