## 一、觸發

第二次從 Repository 首頁進行無記憶交接時，沿 README → v2.8 → 快照-004 恢復。

交叉閱讀現行規則後發現：

## 二、問題確認

問題不是歷史 v2.7 文件存在。

問題是現行規則.md 仍把 v2.7 作為現行交接鏈的一部分。

影響：
新 AI 若在 README 後閱讀規則，會得到 v2.8 與 v2.7 兩個不同版本訊號。

## 三、最小修正

只修改現行規則.md 的兩處舊版本引用：

v2.7 → v2.8

不修改：
- 交接資料-v2.7.md
- 快照-003
- v1.6及更早工程運作文件
- 歷史問題紀錄
- 任何歷史驗收證據

## 五、結論

本次問題已完成最小修正並通過模擬回歸。

這次測試也產生一項新的工程認知：

「建立新版本入口」與「完成所有現行引用同步」不是同一件事。

後續版本更新時，現行入口鏈必須視為一個完整變更集，而不是逐檔憑記憶修改。

這項認知先保存於問題紀錄；不立即建立新的自動化系統。
