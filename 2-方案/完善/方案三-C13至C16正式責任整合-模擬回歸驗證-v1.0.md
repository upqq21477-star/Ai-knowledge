## 二、核心回歸

1. C12 執行後必須進 C13。
2. C13 UNKNOWN 不得直接進 ADOPT。
3. C13 FAIL 必須進 RETURN。
4. C14 ADOPT 才能形成 C15 Current State 更新。
5. DEFER 不污染 Current State。
6. RETURN 不代表問題已解決。
7. C15 必須保留前一版本關係。
8. C16 必須保留完整演化鏈。
9. 歷史不能重新成為 Current。
10. 模擬結果不能轉成 FIELD-PASSED。
