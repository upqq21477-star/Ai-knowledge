## 五、回歸案例 R4：正式清單存在目標，但目標已完成

### 輸入

假設正式清單存在 B1～B4，且目前狀態已顯示 B1～B4 已研究完成，但收到：

```text
重新研究 B1～B4
```

### 預期

來源驗證不能只檢查「存在」。還必須檢查：

```text
存在 = PASS
狀態 = 已完成
→ 不得直接當成下一批
→ 必須判斷是否存在重新開案理由
```

### 模擬結果

```text
PASS
```

說明：本修正不是單純「名稱存在檢查」，而是「存在＋狀態＋順序」檢查。

## 十、失敗模式檢查

| 失敗模式 | 修正後處理 |
|---|---|
| 不存在的功能 | BLOCK |
| 舊文件宣稱下一批 | 不具功能權威性 |
| 交接與正式清單衝突 | 回正式來源重新解析 |

| 正式清單不可取得 | BLOCK |
| 研究文件反向創造功能 | 禁止 |
| 正式清單變更 | 重新計算下一批 |
| 正確下一批 B1～B4 | ALLOW |
