# 上下文成本與可靠性控制方案

版本：v1.0
類型：方案對照組（Control Group）
狀態：【對照組；待實測】

## 核心運作理念

以最小充分 Context 完成任務。

先測量需要多少 Context，
再測試 Context 是否可靠，
最後檢查輸出是否有證據支撐。

發現 Context 造成問題時，
回調 Context 組成並重新驗證。

Solution 不保存執行細節；
執行由所屬 System 負責。

## 啟動路由

需要測 Context 數量
→ 上下文預算與充分性測量系統

需要測 Context 可靠性
→ 上下文可靠性測試系統

需要檢查輸出失真
→ 上下文證據一致性與幻覺檢測系統

完整檢查
→ C03 → C04 → C05

需要搜尋
→ 研究問題、資料探索與搜尋系統

需要組裝 Context
→ AI知識與上下文交接系統

需要證據判定
→ 來源、證據與研究採用判斷系統

需要更新
→ 知識比較、更新與資料演化系統

需要結構修正
→ 問題解決與新系統建立流程

## 完成條件

Context 足以完成任務；
可靠性可驗證；
輸出可追溯；
不因 Context 不足或過量產生未解釋失真。
