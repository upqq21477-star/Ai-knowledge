# 資料來源與使用追溯最小原則

版本：v1.0  
狀態：【候選知識；已完成外部方法比對；待實際案例驗證】  
日期：2026-09-17

## 一、目的

定義共同資料層最小的「來源（Source）」「證據（Evidence）」「主張（Claim）」與「使用追溯（Traceability / Lineage）」關係，讓 AI 或系統在使用資料後能回答：

```text
使用了什麼？
來自哪裡？
使用的是哪個版本／狀態？
為什麼可以使用？
產生了什麼結果？
```

本原則不建立中央 Evidence Engine，也不要求所有資料都保存完整事件級追蹤。

## 二、核心區分

```text
Source    = 資料從哪裡取得
Evidence  = 支持某個主張或判定的具體依據
Claim     = 被提出、保存或驗證的主張
Trace     = 某次工作使用了哪些對象
Lineage   = 對象如何由來源／前置對象演化而來
```

來源可以產生證據，但來源本身不必然就是證據。

## 三、最小追溯鏈

最低可接受模型：

```text
Source
  ↓
Evidence
  ↓
Claim / Decision
  ↓
Used By
  ↓
Result
```

對資料／知識本身的演化，則可表示：

```text
Parent / Source Object
        ↓
Derived / Transformed
        ↓
Current Object / Version
```

不要求每個普通閱讀動作都建立事件。只有當追溯對正確性、驗證、變更、稽核或重現具有實際價值時，才提高追蹤粒度。

## 四、追溯最小欄位

當某次工作需要可重現追溯時，至少保留：

```text
使用對象 Identity
使用版本／狀態（若適用）
Source / Evidence reference
使用目的／任務
時間
產出結果或決策
```

若只是一般搜尋瀏覽，不需要強制建立完整使用紀錄。

## 五、與 Relationship 的關係

Traceability 不是另一套獨立關係系統。

共同關係模型可表達：

```text
Object A → derivedFrom → Object B
Claim → supportedBy → Evidence
System → references → Knowledge
```

而「某次工作實際使用了哪些對象」屬於使用紀錄／工作上下文，不能全部壓縮成永久 Relationship。

因此：

```text
Relationship = 相對穩定的結構關係
Trace Record  = 某次工作發生的使用事實
Lineage      = 可長期追蹤的來源／演化鏈
```

## 六、外部方法比對

Backstage Catalog 將實體、來源、關係與生命週期分開管理；其 catalog graph 以實體為節點、relations 為邊，支援 ownership、inventory、search、lifecycle、dependency mapping 等用途。這支持「關係是可查詢的結構資料，但不應把所有使用事件都當成永久關係」的方向。

Backstage 的 catalog processing 也保留來源與處理時間，並在關係產生後建立圖結構；這可作為來源、關係、追溯分層的參考，但不代表本專案需要完整複製其資料庫模型。

## 七、避免追溯系統膨脹

追溯不是「所有動作全部記錄」競賽。

應依需求提高粒度：

```text
普通瀏覽
→ 不必產生完整 Trace

正式研究／判定
→ 保存主要 Source / Evidence / Claim

重大變更／驗收
→ 保存使用對象、版本、依據、結果

需要重現的關鍵工作
→ 保存足以重建 Context 的使用鏈
```

追溯資料過量會增加儲存、搜尋、Context 組裝與維護成本，因此「可追溯」應理解為「在需要時足以回答關鍵問題」，而不是「任何細節永久記錄」。

## 八、最小驗證方法

自然工作中挑選一個實際產出，例如一次正式方案研究或一次變更判定，檢查是否能回答：

1. 使用了哪些資料／知識？
2. 使用的是哪個版本？
3. 主要依據來自哪裡？
4. 哪些內容只是推論而非證據？
5. 最終結果能否回到上述依據？

若現有資料已能回答，不建立新的追溯系統；只補足缺少的共同知識或資料關係。

## 九、禁止事項

- 不把 Source 直接等同 Evidence。
- 不把每次使用都永久建立成 Relationship。
- 不為了「可追溯」而記錄無法產生實際價值的大量事件。
- 不因外部工具存在 lineage 功能就直接複製完整平台。
- 不把追溯紀錄當成真實性裁決器；它只能告訴我們依據與使用鏈，不能自動證明內容為真。
