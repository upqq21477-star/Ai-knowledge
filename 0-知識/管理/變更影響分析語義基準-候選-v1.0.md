## 一、定位

本文件是由既有「變更影響分析最小原則」與「變更影響分析與影響範圍」蒸餾出的候選共同語義。

它不是目前正式 CURRENT Canonical，也不取代兩份原始文件。

## 二、最小共同語義

Impact Analysis 回答：

> 當某一對象發生變更時，哪些其他對象可能需要重新檢查、驗證、遷移、停止使用或進一步確認？

影響分析的目的不是預測所有未來問題，也不是直接決定是否修改。

最小分析鏈：

```
變更對象
→ Identity
→ Direct Relationship / Dependency / Usage
→ 直接影響候選
→ 下游關係
→ Version / Compatibility
→ Validation / Real Work
→ 實際影響
```

必要時再依風險與關係強度縮小分析範圍。

## 三、最小判斷維度

至少考慮：

1. Identity：是否為正確的變更對象。
2. Relationship：有哪些直接／間接關係。
3. Dependency：哪些能力依賴它。
4. Usage：哪些實際工作使用它。
5. Version：哪些版本可能受影響。
6. Compatibility：舊用法能否繼續。
7. Validation：哪些驗證需要重新執行。
8. Lifecycle：是否導致失效、棄用或退休。
9. Data：是否需要遷移或重算。
10. History：是否需要保留舊版本與變更依據。

不是每次變更都必須完整檢查全部維度；深度應依風險與影響範圍調整。

## 四、影響結果語義

至少保留：

- Candidate Impact：可能受影響。
- Confirmed Impact：已由實際關係／測試確認。
- No Impact：已檢查且沒有需要處理的影響。
- Unknown：缺少必要資料，無法判定。

實際更新工作可另外使用：

- Direct Impact
- Indirect Impact
- Potential Impact
- 待確認

這些是分析結果維度，不應被直接等同於「一定需要修改」。

## 五、關係追蹤與停止條件

只有存在足夠理由的實際關係才進入影響追蹤。

不能因主題相近就視為依賴。

每一層至少重新判斷：

```
存在關係
→ 變更是否進入該項目的使用範圍？
→ 是否改變有效條件／輸出／判斷？
→ 是：保留為影響候選
→ 否：保留關係但停止該分支
```

分支可在以下情況停止：

- 沒有新的依賴或使用者。
- 僅主題相關而無實際關係。
- 變更不改變有效條件或輸出。
- 關係已回到已分析項目。
- 繼續追蹤只會產生大量低可信度候選。
- 分析成本已高於預期降低的錯誤風險，且不是高風險核心路徑。

## 六、Impact Analysis 與 Change Decision 必須分離

```
Impact Analysis
→ 影響範圍／風險資訊
→ Change Decision
→ 決定是否修改、如何修改
```

不能由影響分析單獨推出：

- 一定要修改。
- 一定不能修改。

同樣：

`影響大 ≠ 不准修改`
`影響小 ≠ 可以直接修改`

## 七、最小驗證方法

第一次驗證不建立大型 Impact Engine。

選擇一個真實變更案件，人工記錄：

```
變更對象
→ Identity
→ 直接 Relationship
→ 實際 Usage
→ 依賴／下游
→ Version / Compatibility
→ Validation
→ 最終實際影響
```

再比較分析前的候選影響與實際結果。

只有當人工流程在自然工作中持續產生穩定價值，才考慮將其中部分步驟系統化。

## 八、與其他層級的邊界

- Impact Analysis 是共同能力，不應在四個方案各建立一套重複分析器。
- `系統依賴` 提供依賴語義；Impact Analysis 使用依賴進行變更傳播分析。
- `知識更新原理` 處理知識何時／如何更新；Impact Analysis 處理變更可能傳播到哪裡。
- Plan / System / Knowledge 不因被分析就變成同一層。
- Mapping 不是 Canonical Source。
- 本候選不建立完整 Metadata Schema、Relationship Database、Impact Graph 或 Orchestrator。

## 九、驗證限制

Impact Analysis 可能產生 false positive 與 false negative。

因此：

> 影響集合是目前證據下的分析結果，不是保證完整的真實集合。

不能：

- 宣稱可以找全所有影響。
- 把所有依賴直接判成必須更新。
- 把影響項目數量直接當成成本。
- 使用單一固定倍率估算所有變更。
