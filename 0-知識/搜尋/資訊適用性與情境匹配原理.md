# 資訊適用性與情境匹配原理

狀態：**【建立中；已完成外部方法比對；待實際任務驗證】**

## 一、目的

本知識處理：

> 一項資訊即使可信，是否可以用來回答目前這個問題？

適用性不是判斷資訊「真假」，而是判斷資訊與目前任務的情境匹配程度。

## 二、核心區分

```text
可信度
= 這個主張有多少合理證據支撐？

適用性
= 這個可信主張能否用於目前問題？
```

因此：

```text
可信 ≠ 必然適用
不適用 ≠ 必然錯誤
適用 ≠ 證明可信
```

## 三、適用性需要比較的條件

至少檢查：

1. 問題是否相同或足夠接近？
2. 對象是否相同或可合理類比？
3. 時間是否一致或仍可使用？
4. 地域／環境是否一致？
5. 前提條件是否一致？
6. 資料範圍是否一致？
7. 使用目的是否一致？
8. 結果的適用範圍是否超過原資料支持的範圍？
9. 是否存在會改變結論的重要情境差異？

## 四、適用性是程度，而非單純二元判斷

很多情況不是「適用／不適用」兩種，而是：

```text
高度匹配
部分匹配
需要條件轉換
只能作為背景參考
不適合直接採用
目前無法判定
```

實際輸出應保留理由，而不是只給標籤。

外部方法研究也指出，generalizability、external validity、applicability、transferability 等概念雖然名稱不完全一致，但核心都涉及把一個情境產生的結果帶到另一個情境時，必須檢查情境差異；context suitability 更適合視為連續程度，而非單純二元結果。citeturn0search0turn0search4

## 五、適用性的最小判斷模型

```text
目前問題
↓
目前對象／情境
↓
資料原本的對象／情境
↓
比較差異
↓
判斷差異是否影響主張成立
↓
判斷可直接使用、條件使用、背景使用或不使用
```

## 六、常見情境差異

### 1. 時間差異

舊資料可能曾經正確，但制度、技術、價格、政策或市場已改變。

因此：

```text
歷史正確
```

不等於：

```text
目前可直接採用
```

### 2. 對象差異

某一族群、產品、模型或地區的結果，不應無條件推廣到另一對象。

### 3. 條件差異

結果可能只在特定前提下成立。

若目前問題不具備該前提，不能直接套用。

### 4. 範圍差異

局部結論不能直接擴張成全域規則。

### 5. 目的差異

同一份資料可以適合回答 A 問題，但不適合回答 B 問題。

因此「資料本身有價值」與「資料適合本次研究」是不同判斷。

## 七、適用性與直接性

判斷時應優先尋找與目前問題直接對應的資料。

若資料需要經過多層推論才能套用，應降低直接採用程度，並明確說明推論鏈。

例如：

```text
原研究 → 同一對象、同一條件 → 直接支持

原研究 → 相似對象、部分條件不同 → 間接支持

原研究 → 不同對象、不同條件 → 只能作為背景或類比
```

這與證據評估中的 indirectness 概念相呼應，但本知識不把醫學 GRADE 直接移植成通用分數制度。Cochrane 的 GRADE 方法將 indirectness 視為判斷證據確定性的重要因素之一。citeturn1search0turn1search2

## 八、適用性與可信度的先後關係

一般流程為：

```text
先確認主張與來源
↓
判斷是否有足夠支撐
↓
再判斷是否符合目前情境
↓
最後決定本次是否採用
```

但實務上兩者可以反覆交互檢查。例如發現情境不匹配後，可能需要重新尋找更適合的資料，再重新比較可信度。

## 九、適用性不足時的處理

不是只有「丟棄」一種選擇。

可以：

- 尋找更直接的來源
- 限縮結論適用範圍
- 明確加入條件
- 作為背景資料
- 作為類比或假設來源
- 標記待確認
- 不採用

因此適用性分析也是搜尋擴展與研究迴圈的回饋點。

## 十、AI 輔助限制

AI 可以協助：

- 抽取兩個情境的差異
- 對照對象、時間、條件、範圍
- 找出可能的間接推論
- 提出需要驗證的差異

但 AI 不應僅因兩段文字語義相似，就判定資訊適用。

真正的適用性判斷需要確認實際條件。

## 十一、最小實際流程

```text
1. 明確目前問題與使用目的
↓
2. 明確資料原本回答的問題
↓
3. 對照對象、時間、條件、範圍與環境
↓
4. 找出重要差異
↓
5. 判斷差異是否影響主張
↓
6. 判定直接採用／條件採用／背景參考／不採用／待確認
↓
7. 保留適用性理由與限制
```

## 十二、與其他知識的邊界

```text
來源與證據
→ 來源與證據關係

資訊可信度與主張驗證
→ 主張的支撐與可信程度

知識比較
→ 兩份內容之間的關係

適用性與情境匹配
→ 內容與目前任務的匹配程度

採用判斷
→ 綜合以上結果，決定本次是否使用
```

## 十三、外部方法比對後的結論

外部研究對 applicability、generalizability、external validity 與 transferability 的處理顯示，情境匹配需要考慮研究對象、設定、介入／內容、結果與證據等因素，而且不同領域的具體判準可以不同。citeturn0search1turn0search2

因此 Ai-knowledge 目前採用跨領域最低原理：**先辨識情境差異，再判斷差異是否影響主張可用性；不建立單一適用性分數。**
