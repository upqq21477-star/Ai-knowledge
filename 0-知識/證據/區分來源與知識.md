# 區分來源與知識

> 一句話：不要把原始資料、證據與整理後可重用的結論混成同一層。

## 核心原理
來源回答「資訊從哪裡來」；知識回答「經過整理與驗證後，下次可以直接重用什麼」。

原始文章、文件、對話、實驗結果與人工智慧輸出都可能是來源，但不一定值得直接保存成知識。

```text
來源 → 讀取／比較／驗證 → 結論 → 判斷是否可跨場景重用 → 知識
```

## 適用情境
研究後判斷哪些內容值得長期保存；多個來源提供相似或互補資訊時；避免大量原始資料直接堆進知識庫。

## 不適用情境
需要保存完整研究材料、原始資料或一次性專案紀錄時，應留在研究資料或應用中。

## 實務方法／注意事項
建立知識前先問：拿掉來源名稱後，內容能否獨立理解？下一次遇到相似問題時是否仍然有用？若不能，通常不應升格為正式知識。

## 我的補充
「研究過」不等於「已形成可重用知識」。
