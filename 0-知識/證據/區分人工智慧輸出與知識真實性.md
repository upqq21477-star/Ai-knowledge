# 區分人工智慧輸出與知識真實性

> 一句話：人工智慧產生的內容是候選輸出，不應因為完整或合理就直接視為已驗證的知識。

## 核心原理
模型可以產生假設、整理、推論與建議，但流暢度不等於正確性。進入知識庫的內容，應經過與任務需求相稱的驗證。

```text
人工智慧輸出 → 拆解主張 → 查證／實驗／比較 → 確認條件 → 可重用結論 → 知識
```

## 適用情境
人工智慧研究、分析、設計、整理資料，多輪對話產生候選方案，以及需要長期保存對話結果時。

## 不適用情境
純粹腦力激盪、創作草稿或已明確標示為尚未驗證的方案。

## 實務方法／注意事項
至少區分已驗證事實、有限制的結論、尚未驗證假設，以及建議或創意。後兩類不要直接升格為正式知識。

## 我的補充
新人工智慧接手時，必須知道哪些內容已確立、哪些只是過去提出的方案。
